# 标题创作原则

## 固定语境

- 以中年男主播的口吻，写给与他互有牵挂的中老年女性网友。
- 把双方理解为红颜知己式关系：亲近、暧昧、互相惦记，但不必假定现实婚恋身份。
- 写成主播正在对“她”说的一句话，不写成内容摘要、歌曲介绍或营销分析。

## 从字幕出发

1. 分别理解开场口播、歌词和结尾口播。
2. 找出这份素材独有的感情核心、关系动作和情绪变化。
3. 提炼 2–3 个具体情感关键词，例如“久等、舍不得、亏欠”，不要只写“爱情、感动”一类宽泛词。
4. 允许使用标题库从未出现过的情绪和词语。标题库没有覆盖的内容不构成限制。
5. 不从参考标题里挑关键词，不先选句式再把字幕词语填进去。

## 三种风格

### 暧昧版

- 必须以“亲爱的”开头。
- 表达两个人之间的喜欢、想念、守候、依赖、心动、亏欠或不舍。
- 把字幕中的感情核心变成一句面对她的真心话。
- 可以直白，也可以克制，但要让人感到两人的关系不同于普通网友。

### 祝福版

- 必须以“姐姐”开头。
- 把字幕中的情绪转化成对她的具体祝愿，例如健康、平安、顺遂、被珍惜、愿望实现或走出低落。
- 让祝福与这份字幕有关，避免批量套用“幸福快乐、万事如意”。
- 可以带少量牵挂和暧昧，但落点必须是祝福她。

### 急迫版

- 不要求称呼开头。
- 传达主播期待她出现，并给予点赞、打赏、留言、支持或人气帮助。
- 可以直接提出支持，也可以通过“现在需要你、别让我独自面对”等方式间接表达。
- 允许为紧迫感虚构字幕里没有的情境，例如人气被反超、比赛受阻、最后机会或对手施压。
- 即使虚构情境，也要让她能感到“主播正在等我的支持”，不能只写无关的冲突新闻。

## 长度与原创

- 将去除首尾空格后的 Unicode 字符数控制在 20–30 字，标点计入长度。
- 每份素材只生成 1 个标题。
- 先从内容命题出发，再选择表达方式。不要仿写、改写或拼接参考库中的标题。
- 在同一批次轮换表达角度，例如告白、承诺、设问、具体场景、危机、请求或祝愿。
- 避免批内重复核心句式、长片段和相同结尾。
- 不在标题中加入歌手名、歌曲名或序号。
- 使用适合 Windows 文件名的中文标点，不使用 `<>:"/\|?*` 或不可见字符。

## 交付前检查

逐条确认：

1. 标题准确体现用户指定的版本。
2. 关键词来自字幕，不受参考库词汇范围限制。
3. 标题符合人设和双方关系。
4. 标题为 20–30 字，称呼规则正确。
5. 标题没有照抄参考库，也没有与本批其他标题高度雷同。
6. 标题可以直接作为 Windows 文件名。

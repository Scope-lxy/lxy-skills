# 标题创作原则

## 固定语境

- 以中年男主播的口吻，写给与他互有牵挂的中老年女性网友。
- 把双方理解为红颜知己式关系：亲近、暧昧、互相惦记，但不必假定现实婚恋身份。
- 写成主播正在对“她”说的一句话，不写成内容摘要、歌曲介绍或营销分析。

## 从字幕出发

1. 分别理解开场口播、歌词和结尾口播。
2. 找出这份素材独有的感情核心、关系动作和情绪变化。
3. 提炼 2–3 个具体情感关键词，例如“久等、舍不得、亏欠”，不要只写“爱情、感动”一类宽泛词。
4. 允许使用标题库从未出现过的情绪和词语。标题库没有覆盖的内容不构成限制。
5. 不从参考标题里挑关键词，不先选句式再把字幕词语填进去。

## 口吻校准

- 写成自然、直接、有明确感情的口语，像中年男主播私下发给一位具体女性的消息，不像公开发表的文案。
- 让他亲口说出自己的感受、反应或想做的事，例如想她、在乎她、心疼她、舍不得、放不下、会心软、想陪她或想留住她。这里只是表达方向，不是必用词表。
- 真诚来自具体的关系反应，例如“少了你的消息，这一天都没滋味”；不要靠宏大承诺、人格升华或漂亮概念证明深情。
- 优先使用日常说法，例如“只要你还在”“我越来越舍不得”“我真的很在乎”“我只想陪着你”。按素材变化表达，不把这些短语拼成固定公式。
- 少用只有作者觉得漂亮、现实中很少对人说的抽象比喻，例如“调成你的频道”“存在就是答案”“把自己活成更好的人”“把疲惫交给温柔”“把温暖放回心里”。
- 把字幕里的场景当作爱意的落点，而不是标题本身。标题的主句要落到“我对你有多在乎、舍不得、想见、想等或想守着你”这类个人表达上。
- 标题库主要校准对应版本的直接程度、亲密感、句子节奏和情绪浓度。可以直接借用贴合当前素材的自然用词、短表达和说话方式，但不要照抄完整标题，也不要把一种句式重复用于整批素材。
- 写完后朗读一遍。若不像这个人会真诚地对她说出口，或者删掉“亲爱的”后只剩泛泛鸡汤，就重写。

### 爱意强度

- 暧昧版的主句必须让对方不看字幕也能听出：主播爱她、最舍不得她、放不下她、一直在等她、心疼她，或真想靠近和守着她。可直接说“我爱你”，但只有符合这条字幕时才用，不能批量套用。
- “惦记你”“陪着你”“节日快乐”“有你真好”单独出现时，爱意通常太弱；要补出主播自己的选择或反应，例如“最放不下的人是你”“一直等的是你的消息”“你难过我就心疼”。
- 节日、远方、歌曲、天气或日常场景只能帮标题落地，不能代替表白。删去这些场景后，主句仍应清楚地传达爱意。

| 爱意太弱 | 更直接的方向 |
| --- | --- |
| 亲爱的，隔着这么远，我一直惦记你 | 亲爱的，隔着这么远，我最舍不得的人还是你 |
| 亲爱的，这个节日我想起了你 | 亲爱的，这个节日隔着人海，我心里最放不下的还是你 |
| 亲爱的，有你陪着我就很开心 | 亲爱的，你一句消息就能让我开心很久，因为我真的很在乎你 |

右列用于校准情感浓度，不是可替换关键词的模板。每条标题仍须从该份字幕的具体场景和关系动作出发。

### 暧昧版边界案例

以下案例用于判断自然度和暧昧度。右列中贴合素材的用词、短表达和说话方式可以直接借用，但不要把完整标题原样用到另一份素材上，也不要整批重复同一种句式：

| 避免 | 改进方向 |
| --- | --- |
| 亲爱的，因为你值得，我愿把自己活成一天比一天更好的人 | 亲爱的，我想让你看到更好的我，因为我真的很在乎你 |
| 亲爱的，你什么都不用做，光是在远方就足以让我安心 | 亲爱的，只要知道你还在，我心里就踏实，日子也有盼头 |
| 亲爱的，走过半生才遇见你，我愿把所有疲惫交给你的温柔 | 亲爱的，遇见你以后，我这个逞强的人也开始有了牵挂 |
| 亲爱的，我愿慢慢调成你的频道，陪你走过每个漫长夜晚 | 亲爱的，我愿意慢慢懂你，陪你熬过那些没人知道的夜晚 |

左列中的词语不是一律不能用，结合素材后说得自然就可以。问题在于这些整句话像经过包装的文案，感情被概念和比喻挡住了。右列更贴近预期，因为主播直接说出了“在乎、踏实、牵挂、想懂她”的关系反应。

## 三种风格

### 暧昧版

- 必须以“亲爱的”开头。
- 表达两个人之间的喜欢、想念、守候、依赖、心动、亏欠或不舍。
- 把字幕中的感情核心变成一句面对她的真心话。
- 可以直白，也可以克制，但必须有无法误解为普通问候的个人感受或关系信号，让人感到两人的关系不同于普通网友。只写“惦记、陪伴、祝福”不够，必须让她明确感到自己被爱、被等待或被放在心上。

### 祝福版

- 必须以“姐姐”开头。
- 把字幕中的情绪转化成对她的具体祝愿，例如健康、平安、顺遂、被珍惜、愿望实现或走出低落。
- 让祝福与这份字幕有关，避免批量套用“幸福快乐、万事如意”。
- 可以带少量牵挂和暧昧，但落点必须是祝福她。

### 急迫版

- 不要求称呼开头。
- 传达主播期待她出现，并给予点赞、打赏、留言、支持或人气帮助。
- 可以直接提出支持，也可以通过“现在需要你、别让我独自面对”等方式间接表达。
- 允许为紧迫感虚构字幕里没有的情境，例如人气被反超、比赛受阻、最后机会或对手施压。
- 即使虚构情境，也要让她能感到“主播正在等我的支持”，不能只写无关的冲突新闻。

## 长度与原创

- 将去除首尾空格后的 Unicode 字符数控制在 20–30 字，标点计入长度。
- 每份素材只生成 1 个标题。
- 先从内容命题出发，再选择表达方式。不要仿写、改写或拼接参考库中的标题。
- 在同一批次轮换表达角度，例如告白、承诺、设问、具体场景、危机、请求或祝愿。
- 避免批内重复核心句式、长片段和相同结尾。
- 不在标题中加入歌手名、歌曲名或序号。
- 使用适合 Windows 文件名的中文标点，不使用 `<>:"/\|?*` 或不可见字符。

## 交付前检查

逐条确认：

1. 标题准确体现用户指定的版本。
2. 关键词来自字幕，不受参考库词汇范围限制。
3. 标题符合人设和双方关系。
4. 标题为 20–30 字，称呼规则正确。
5. 标题没有照抄参考库，也没有与本批其他标题高度雷同。
6. 标题可以直接作为 Windows 文件名。
7. 标题经得起朗读，没有生硬比喻、概念化表达或刻意拔高。
8. 暧昧版删去称呼后，仍能清楚看出主播对“她”的在乎、牵挂或不舍。
9. 暧昧版脱离视频单独阅读时，对方能直接感到主播的爱意，而不只是普通关心或节日问候。

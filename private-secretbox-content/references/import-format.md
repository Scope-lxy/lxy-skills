# 日记导入包格式

用于用户明确要求“可导入”“批量导入”或配图落盘时。内容本身与图片采集分开处理。

## 目录结构

导入根目录下每套日记一个日期加主题的目录，例如：

```text
日记内容-首批50-导入包/
  2026-06-04 梧桐车影/
    正文.txt
    01.jpg
    02.jpg
    03.jpg
```

每套必须有一个 UTF-8 `正文.txt`；图片按 `01.jpg`、`02.jpg`、`03.jpg` 顺序编号，不放 CSV、来源说明或临时文件。没有图片的日记只保留正文。

## 图片节奏

默认以3图为主，混合2图、1图和无图，避免每套都严格一张。若用户给出总套数和图片比例，按用户比例；否则沿用“3图约36%、2图约14%、1图约10%、无图约40%”的近似节奏并四舍五入，总图片数和索引必须一致。

## 外部来源记录

来源 CSV 放在导入根目录外，至少包含 `ID`、`fileName`、`sourcePageUrl`、`originalImageUrl`、`license` 字段；每张图一行、URL 不重复、文件名能对应真实文件。优先使用有明确授权说明的来源（例如 Pexels），并保留来源页和许可证链接。

## 视觉取舍

真实生活里的品牌、手机/麦克风等设备标识、中文店招可以保留。需要替换的是会把场景明确指向欧美或其他海外地区的强线索，例如外国国旗、外语路牌/交通标线、海外出租车或典型异国建筑室内。优先选择中国城市、中文环境、普通餐馆、排练室、街巷、书店和自然景物；不因“无品牌”而把图片处理成失真的样板图库。

## 验收清单

- 目录数、`正文.txt` 数和用户要求的套数相同。
- 图片扩展名为 JPG、可解码、非空且单张小于5MB。
- 图片数量与索引和来源 CSV 一一对应，来源 URL 唯一。
- 导入目录内无额外说明文件；说明和来源均在包外。
